### 🚀 Introducing iyi

**[iyi](https://iyi.dev)** is a new programming language with Crystal's syntax and fast compile times. A module compiles against its dependencies' declarations, not their bodies, so builds stay fast as your codebase grows.

- 🌐 Website: [iyi.dev](https://iyi.dev)
- 💻 Source: [github.com/iyilang/iyi](https://github.com/iyilang/iyi)
- 📦 Packages: [packs.iyi.dev](https://packs.iyi.dev)

### 🔭 What I'm working on

- **[iyi](https://github.com/iyilang/iyi)** - A programming language with Crystal's syntax, designed for fast compiles. Modules compile against their dependencies' declarations, not their bodies.
- **[Kemal](https://kemalcr.com/)** - The most popular web framework for Crystal. Fast, Effective, Simple. 5M+ downloads since 2015.
- **[gcry](https://github.com/sdogruyol/gcry)** - A native conservative mark-sweep garbage collector for Crystal. Aiming to eliminate Crystal's dependency on Boehm GC. ~89% of Boehm throughput with ~0.95x RSS on Linux.
- **[cryload](https://github.com/sdogruyol/cryload)** - CI-first HTTP benchmarking tool that actually fails your builds.
